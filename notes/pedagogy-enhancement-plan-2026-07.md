# Pedagogy Enhancement Plan — `system_ident` docs (2026-07-05)

> Produced by a background docs-audit agent (propose-first). Scope was limited to
> **figures/visual explanation** + **learner scaffolding**. Nothing here is committed
> policy; it is the feedstock for the doc-improvement work. Grounded in a full read of
> `docs/tutorial/*.qmd`, `docs/examples/*.qmd`, `docs/index.qmd`, `README.md`, the plot
> helpers (`docs/sysid_plots.py`, `make_assets.py`, per-example `*_demo.py`), and
> `.llm/pintelon-schoukens-mimo-fit.md` / `.llm/overview.md`.

## 1 · Verdict

The docs are pedagogically **well above average and visually mature**: a shared house-style
plotting library (`docs/sysid_plots.py`) gives every worked example the *same* nine-panel
diagnostic arc (design → time series → Bode/coherence → residuals → CRB recovery → safety →
convergence → overlay); all figures are data-driven with no hardcoded axis ranges; the hero on
`index.qmd` and example 01 already ship live animations and an OJS slider; and
`why-optimal-excitation.qmd` is a model of feasibility-gate discipline — every number is a real
package run and the crest-factor claim is honestly bounded to plant-referred units. The two
biggest gaps: **(a)** a concrete feasibility-gate violation in `examples/10-srm-hsts.qmd` — the
0.672/0.676 Hz doublet collapse is labeled a "resolution / identifiability limit" when the
codebase's own `fit_block_decoupled` and the project memory both say it is a *spatial* doublet
resolvable with **no** frequency super-resolution (trap the docs are supposed to teach against);
and **(b)** the entire MIMO / rank-1 joint-modal method that examples 09–10 depend on has **no
tutorial home** — a newcomer meets `R_k = φ_k ψ_kᵀ`, shared poles, and block-decoupling cold.

## 2 · Learning-arc map

**Intended path** (nav + cross-links): `index.qmd` (hero animation, "Read the method" /
"Worked examples" CTAs) → `tutorial/overview.qmd` (loop mermaid + the five moves) →
`model.qmd` → `fisher.qmd` → `closing-the-loop.qmd` → `safety-and-ops.qmd`, with
`examples/01…10` as the executable ladder (01 is the annotated on-ramp).

**Where it breaks:**
- **No stated on-ramp or prerequisites.** `overview.qmd` opens the "Why Fisher information?"
  section with the full Fisher integral (lines 151–158) before the reader has seen a plot or run
  anything, and that page carries *no* figure. Neither `index.qmd` nor `examples/index.qmd`
  states reading order or which tutorial page each example assumes.
- **The 06 → 07 cliff.** Examples 01–06 are live teaching plants; 07–10 are `freeze:true`
  (compiled CDS twin, DARM, rank-1 modal, real SRM). The jump from 06 (2×2) to 07 (compiled
  `x1hsts6dof`) is large and only softly flagged.
- **Rank-1 modal fit has no tutorial.** Examples 09/10 introduce shared modal poles, rank-1
  residues, IQML/sample-ML, and block-decoupling — none appears in any `tutorial/*.qmd`.
  `closing-the-loop.qmd` stops at SISO GML.
- **Resolution / record-length is taught only in code comments** (`# T_fft > 3/f_min`, `df ≈ …`)
  plus `examples/10`; no tutorial page covers this first-class knob.
- **Interactivity is a one-off.** Only `examples/01` §"Try it yourself" has a knob.

## 5 · Feasibility-gate prose audit

| Location | Offending language | Verdict & fix |
|---|---|---|
| `examples/10-srm-hsts.qmd:141–142` | "…exactly the unresolvable clusters. **This is a resolution / identifiability limit**, not a fitting failure." | **VIOLATION.** The 0.672/0.676 pair is a **spatial** doublet: `mimo_fit.py:381` `fit_block_decoupled` + memory `srm-doublet-is-spatial` say it is resolvable "with no frequency super-resolution" by fitting the orthogonal {L,P,V}/{T,R,Y} blocks separately. The collapse is a limit of the shared-pole full-MIMO model **as configured** (parameterization/model-order — trap #6). **Fix:** relabel as "a limit of the shared-pole fit, resolved by the block-decoupled fit" + figure #2. Any genuine *frequency*-resolution claim must compute `SNR·N` vs `(Γ/Δf)⁴` (figure #1). |
| `examples/10-srm-hsts.qmd:65` | "…what makes **0.004 Hz the practical resolution knee** here." | **VIOLATION (framing).** `df`/ringdown correctly gates **Q of well-separated modes** (keep, it's quantified) but is invoked to explain the **doublet**, which is spatial. **Fix:** keep the ringdown→Q argument with its numbers; remove "resolution knee" as the doublet's explanation. |
| `examples/10-srm-hsts.qmd:135–140` | "The tightest doublets **collapse**… each cluster collapses to a single mode." (as inherent) | **Under-modeling as data limit.** `srm_modal_demo.py:67` fits `distinct_oracle_modes` (13, doublets pre-collapsed). **Fix:** frame as "under the 13-shared-pole model we chose; block-decoupled recovers both." |
| `examples/03-fabry-perot-cavity.qmd:13` | "the identification is **signal-to-noise limited**." | **Minor/soft.** Example succeeds (f_c <0.5%). **Fix (low pri):** drop the "limited" label or cite the achieved σ/θ. |
| `examples/10-srm-hsts.qmd:144–152` | (process-disturbance CRB) | **Exemplary — keep.** Correctly injects a disturbance to define an honest CRB on a noise-free twin. Positive model to cite. |

(No unquantified "fundamental/physical limit" language in `tutorial/*.qmd`; `safety-and-ops.qmd:7`
"physical limits trigger an abort" is operational, not an estimation claim.)
